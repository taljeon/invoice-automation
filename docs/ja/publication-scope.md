# 公開用コピーの構成と除外範囲

[English](../publication-scope.md) | [日本語](publication-scope.md) | [README](../../README.ja.md)

このパッケージは、運用実装のソースから必要なファイルを選び、**新しいファイルツリー**として用意したものである。元のGitリポジトリーの複製でも、元の履歴を含む配布物でもない。2026-09-17に、この情報を整理したコピーの公開がユーザーにより承認された。元のリポジトリーは非公開のままとし、サービスのデプロイは今回の公開に含めない。

## 含めた内容

- React画面：PDFの選択・ローカルプレビュー、明細の確認・編集、行の追加・削除、履歴、CSV出力、クラウド認証UI。
- サーバー処理：PDFレンダリング → Visionによるテキスト抽出 → LLMによるJSON構造化 → 会社名の正規化 → 行の変換 → ジョブ結果の保存。
- 状態と境界：クライアントによるジョブの購読、所有者別のFirestoreパス、Storageのジョブパス、認証済みの補助HTTP API、セキュリティルール。
- 変換規則：40列のCSV仕様、quote escaping、CRLF、Shift-JIS、半角カタカナ、合成データ向けと明示した割増方針。
- 架空の入力：コードで生成するPDF 2件と明細3行、仕入先3社・船舶3隻のサンプルマスター。実際の文書のコピーでも、一部を匿名化した元データでもない。
- アルゴリズムの参照コード：文字列の類似度、キャッシュ、相互検証、反復結果の比較、旧HTTP処理。有効な処理フローと区別してコードマップで説明している。
- 英語・日本語のREADMEと、両言語で同じ技術的詳細を記載した概要・詳細設計・設定・制約文書、再現可能な検証コマンドと合成テスト。

## 除外・置換した内容

| 対象 | 処理 |
|---|---|
| `.git`、過去のcommit/branch/tag/remote/author metadata | 取り込まない |
| 実際の請求書、CSV・Excelのエクスポート資料、DB・バックアップ、生ログ | 取り込まない |
| 顧客・仕入先・船舶の名前・コード・頻度表 | 合成マスターに置換 |
| 既存の運用プロジェクト・bucket・フォルダー・アドレス・環境ファイル | 除外し、利用者自身の環境で入力する空の設定例に置換 |
| キー・token・runtime credential設定 | 除外。AI用の秘密情報はサーバーのSecret Managerの境界として説明 |
| 議事録・内部調査資料・既存の画面キャプチャー・private文書 | 除外。コードの動作を基に公開用の説明を新規作成 |
| 顧客別の価格条件 | 計算構造を維持し、デモ用の閾値・倍率に置換 |
| 以前の生成物である`functions/lib`、build output、dependencies | ZIPから除外。各環境でロックファイルを使用して再生成 |
| 所有権・公開許可に関する推定、根拠のない成果数値 | 新たに主張しない |

元の運用環境の値に対応する置換辞書・元データの場所・private repositoryへのリンク・過去のコミットIDは、このパッケージに含めない。一般的なアルゴリズムの説明にも、元の顧客を特定する手掛かりを再び記載しない。

## 公開用の準備で変更した動作

単純に文字列を削除するだけではレビュー可能なコピーにならない箇所について、動作も整理した。

- アカウントなしで閲覧できる標準のオフラインデモを用意。任意のPDFを実際にOCRしたかのようには表示しない。
- 行IDと元の文書IDの一貫性を維持し、1件のPDFに対する編集が別のPDFに複製されないよう修正。
- 保存処理のユーザーセッションを固定し、アカウント変更後に到着した応答と後続の書き込みを拒否。
- 明細が100件を超えると過去のデータを自動削除していた動作を削除。
- 現在の画面と履歴のCSVロジックを統合し、行ごとの丸め結果と表示合計を一致させ、数量が未確定の場合はexportを拒否。
- ブラウザーでのAIキー入力とlocalStorageへの保存を削除。参照マスターのマッチングはローカルの合成データで処理。
- HTTP認証、ジョブ・PDFの所有権確認、サーバーを既定で無効にする設定、重複ジョブのclaim、Storageの上書き拒否を追加。
- サーバーのPDFページ数制限を超えた場合は、通知せずに切り詰めることなく拒否。ローカルPDFレンダラーと最新の互換依存関係を検証。

## GitHubにアップロードする単位

`python3 scripts/export-public-package.py`は、パッケージの隣に次の2ファイルを生成する。

- `invoice-automation-public.zip`：レビュー対象のソース・文書・合成サンプルのみを含むアーカイブ。
- `invoice-automation-public.manifest.json`：各ファイルのサイズとSHA-256、ZIPのSHA-256、Git履歴が除外されているかの記録。

アーカイブには`LICENSE-NOTICE.md`も含まれる（[日本語版](../../LICENSE-NOTICE.ja.md)）。2026-09-17に、確認済みコピーの公開がユーザーにより承認された。このソースにMITなどのオープンソースライセンスは選択・付与していない。公開状態とライセンスの付与は別であり、第三者の依存パッケージにはそれぞれのライセンスが引き続き適用される。

## 公開とサービス運用は別の段階

コード公開の承認は、実際のサービスのデプロイ・ユーザーデータのアップロード・有料OCRの実行を承認するものではない。技術的な検証結果と残る依存関係・運用上の制限は[検証記録](verification.md)に、設計上の制約は[limitations](limitations.md)にそれぞれ記録している。
